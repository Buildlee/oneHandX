# v0.6 UI 重制与验证记录

日期：2026-10-27。本版为试用版，包名仍为 `io.buildlee.onehand`，沿用现有 debug 签名、Java / AppCompat 和手势引擎，没有新增运行依赖或网络权限。

## 已实现

- 主界面分为「手势、面板、设置」，将几何参数、识别和场景规则移到对应页面。保留每手柄的映射、长度、位置与不透明度；边距和触摸宽度沿用原有全局设置。
- 手柄页同时展示斜上、直滑、斜下的方向与动作，短滑 / 长滑切换，滑动保持 / 长按收进进阶区域。
- 动作选择支持搜索、分类、空结果和兼容性说明。历史实验动作放入高级分类，仍可编辑旧绑定。
- 六种原生反馈共用 `FeedbackView`：贴边曲面、细线箭头、圆形箭头、弧面箭头、柔和曲线、极简指示。
- 曲面保持竖直，斜向手势只旋转箭头；背景、箭头、轮廓独立设色，支持 RGB 和六位色值。背景透明度 0% 为不透明、100% 为完全透明，箭头和轮廓保持独立。可恢复默认配色。
- 试滑与实际服务共用绘制器。实际反馈使用不可触摸的独立浮层，不扩大手柄热区。左右镜像与收回淡出均已接入，减少动态效果时立即收回。
- 跟随系统 / 浅色 / 深色主题，改进说明文字对比度、控件读屏信息、浮层关闭入口和触控尺寸。
- 导入先校验版本与字段类型，展示变更数量、恢复默认的项目数和缺失应用，再确认覆盖。非法类型不会先清空当前配置。
- Android 11+ 截图区分请求提交与实际保存；失败有反馈，未完成的媒体条目会清理。旧 API 兼容性标注通过 Lint。
- 参数变化拆除手柄时取消延迟任务；立即执行后不再触发保持动作。关闭快速振动后，执行反馈仍按总振动开关处理。

旧版 `anim_style` 0 / 1 / 2 分别映射到极简指示 / 细线箭头 / 柔和曲线。新安装默认贴边曲面。更换样式和配色不改变手势映射，新配色一并写入 JSON 备份。

## 使用与边界

覆盖安装前可先用旧版导出配置。首次开启服务前会说明无障碍用途；更新后若系统关闭了无障碍服务，需要手动重新开启。

「设置 → 外观与反馈」调整曲面外观；「设置 → 系统手势共存」调整边距。默认内移 26dp 是调试起点，不能保证每款手机都避开系统返回。本应用没有加入系统手势接管，也不会自动切换导航模式。

以下仍需真机验证：OPPO 等 OEM 的系统返回竞争、新曲面在高刷下的手感与功耗、权限撤销与后台策略、键盘及横屏组合、受保护窗口截图失败、全部动作与三方应用的兼容性。模拟器通过不等于所有安卓手机通过。

本版没有加入通用录屏、小组件宿主、三星特权功能、定时暂停或完整的系统最近任务列表。面板沿用现有点按操作，未加入连续滑选。历史 v0.5 的真机帧率数据不能作为 v0.6 的性能结论。
