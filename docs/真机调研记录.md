# 真机调研记录：Samsung One Hand Operation+（S23 Ultra / SM-S9180）

> 2026-10-24 · 真机实操（Android 16 · One UI · 1440×3088@600dpi）
> 方法：adb + uiautomator 逐页导航/抓取（只读浏览，未修改任何设置；误触的「添加触钮」已当场删除还原）
> 证据：`work/ohoplus-real/`（每页截图 + UI XML）

## 一、主界面结构（SGPSettingsActivity）

- 顶部：`One Hand Operation +` 标题 + 「更多选项」；主开关 **打开**（当前为启用状态）
- 说明：在屏幕左侧或右侧添加手势触钮…
- **触钮组模型**：每组包含「左侧触钮 + 右侧触钮」，各自独立开关 + 独立颜色图标；
  - 触钮 1 左：`返回键, 返回键, 截屏, 快速工具, 扫一扫, 扫一扫`
  - 触钮 1 右：`返回键, 返回键, 截屏, 快速启动器, 录屏工具, 搜索查找`
  - 共 6 个手势位/侧：短距离 3 方向 + 长距离 3 方向
- 「添加触钮 / 删除触钮」（最多 3 组 = 每侧最多 3 个触钮）
- 「高级设置」：应用程序例外 • 动画 • S Pen 手势
- 「手势设置」：快捷操作 • 滑动距离 • 振动
- 全局滑杆：触摸宽度（小↔大）、大小、位置

## 二、触钮手势页（左侧触钮）

三张卡片：
1. **短距离滑动**（无开关）：圆形方向图标 + 动作名
   - 直线向右 / 对角线向上 / 对角线向下
2. **长距离滑动**（开关，默认开）「当执行较长距离滑动并用手指按住屏幕时，执行不同的操作。」
   - 同上 3 方向
3. **对齐触钮**（开关，默认开）「左侧和右侧保持相同的尺寸和位置」

## 三、手势设置页（关键参数）

| 分组 | 条目 | 真机状态/形态 |
|---|---|---|
| 短距离滑动 | 快捷操作 | 开关（默认**关**）「开始操作后再从屏幕上松开手指」 |
| 短距离滑动 | 手势角度 | 二级设置入口 |
| 短距离滑动 | 滑动距离 | 滑杆（短↔长，约 1/4） |
| 长距离滑动 | 快捷操作 | 开关（默认**开**） |
| 长距离滑动 | 滑动距离 | 滑杆（短↔长，约 1/3） |
| 长距离滑动 | 长距离滑动持续时间 | 滑杆（短↔长，约 1/3） |
| 振动 | 快速振动 | 开关（默认**开**）「识别到手势时立即振动，而不是等到手指从屏幕上松开」 |
| 振动 | 自定义振动强度 | 开关（默认开） |
| 振动 | 振动级别 | 滑杆（低↔高，约 1/5） |

> 「快捷操作」= 识别到手势立即执行（不必等松手）；短滑默认关、长滑默认开。

## 四、高级设置页

| 条目 | 说明 |
|---|---|
| 应用程序例外 | 选择不显示手势触钮且不识别手势的应用（复选列表） |
| 动画 | 动画风格：箭头 1 / 箭头 2 / 箭头 3 / 曲线 / 涂色；箭头颜色、轮廓颜色、恢复默认 |
| S Pen 手势 | 开关「允许 S Pen 使用手势」（S Pen 专属） |
| 适配键盘 | 开关「移动键盘上方的手势触钮，从而不干扰输入」 |
| 系统返回手势 | 开关「在触钮区域外使用系统返回导航手势」 |
| 隐藏触钮 | 横屏模式 / 快捷面板 / 锁定屏幕 / 主屏幕 |
