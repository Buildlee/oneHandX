# 参考项目研究：流体手势（FNG）及同类开源手势项目

> 2026-10-24 · 为 OneHand+ v0.3 功能补齐进行的前置调研
> 方式：官方页 / 指南 / 应用商店描述调研 + 4 个开源仓库 clone 本地通读源码（已清理，见文末说明）

## 一、项目清单与要点

| 项目 | 定位 | 关键要点 |
|---|---|---|
| **Fluid Navigation Gestures（FNG）**<br>com.fb.fluid（作者 Francisco Barroso） | 底部+侧边导航手势；「流体手势」即指它，已停止维护 | 手势：Quick Swipe / **Swipe & Hold**；动作含 Toggle split-screen、Toggle navbar、Keyboard selector、Volume dialog 等；隐藏导航栏需 ADB（policy_control / overscan）；白名单暂停；备份恢复 |
| **Coolboyrajat/Fluid-Navigation-Gesture**（GitHub，非官方延续版） | FNG 反编译延续 v3.0（Java） | 完整动作表（源码确认：SPLIT_SCREEN=7 / KEYBOARD_SELECTOR=8 / TOGGLE_NAVBAR=29 / VOLUME_DIALOG=23 / PREVIOUS_APP=11 …）；每触发器「主动作 + 次要动作（Swipe & Hold）」；导航栏机制 = `Settings.Global policy_control`（隐藏 `immersive.navigation=*` / 恢复 `immersive.none=*`） |
| **Vivid Navigation Gestures**<br>com.ivianuu.oneplusgestures | 手势套件（付费，非开源） | 9 触发区 × 11 手势（含 Hold / Double Tap / Tap）；动作含 Kill App、Menu、Input Method Picker、Toggle Nav Bar；ADB 隐藏导航栏 |
| **Akış Gesture**<br>github.com/omeryol/AkisGesture（MIT） | FNG 的现代继任者（Kotlin / Compose） | Quick Swipe / **Swipe & Hold** / **L 手势**；环形菜单（每边 3 动作）+ 最近应用 Dock；**智能暂停**（锁屏/键盘/横屏/全屏/安装器/相机/通话/黑白名单）；JSON 备份；Shizuku/root 可选。分屏仍调 `GLOBAL_ACTION_TOGGLE_SPLIT_SCREEN`；输入法选择器 = 服务直调 `showInputMethodPicker()`；音量面板 = `adjustVolume(ADJUST_SAME, FLAG_SHOW_UI)` |
| **Evilgodxu/EdgeGesture**（GitHub，Kotlin） | 边缘手势 + 面板套件 | 每边 3 段 × 每段 9 动作（三方向短滑/长滑 + tap/双击/长按）；全屏/横屏双滑防误触；音乐/任务/罗盘面板；freeform 依赖 hidden-api + Shizuku |
| **Fieldtrans/EdgeGesture**（GitHub，LSPosed） | 单手边缘手势（免 root 无障碍 + root 增强） | **直线箭头模式**（松手点击箭头尖位置）与**摇杆光标模式**（Tracker + Cursor）——OHO+ 虚拟触控板的无障碍实现路线；配置导入导出 |
| **XGesture**<br>github.com/qpst4/XGesture | 一体化 OHO+ 竞品（Compose） | 可达性指针 / 浮动光标、宏、剪贴板等；分屏 / freeform 走 Shizuku + 反射 `setLaunchWindowingMode`；音量面板用 `Settings.Panel.ACTION_VOLUME`（本版本采纳） |
| **Smart-Edge**<br>github.com/f4646/Smart-Edge | 侧栏面板（OriginOS 风格） | 拖拽到分屏 / freeform（特权路径）；玻璃拟态主题 |
| **xda/navigation-gestures**（GitHub） | XDA 官方导航手势实验 | AIDL 多进程架构（历史项目，参考价值有限） |

| 长按手柄 | Vivid / EdgeGesture | 每手柄 1 槽位（500ms）✓ 实测 |

| JSON 备份 / 恢复 | FNG / Akış | ✓ 实测 |

| 分屏 / 输入法选择器 | FNG / Vivid / Akış | 接口已实现；Android 16 系统限制（日志实证，见下） |

## 三、Android 16 实测结论（供后续版本参考）

- `GLOBAL_ACTION_TOGGLE_SPLIT_SCREEN` → 返回 false；`ActivityTaskManager: Unknown windowing mode for task=… windowingMode=3`（legacy 分屏模式已移除）
- `showInputMethodPicker()` → `W InputMethodManagerService: Ignoring showInputMethodPickerFromClient of uid …`（第三方被系统拒绝）
- `policy_control immersive.*` → 可写入但系统不生效（前后截图 / 窗口转储 MD5 一致）
- `Settings.Panel.ACTION_VOLUME` → 有效（弹出原生音量面板）
- 无障碍服务禁用会触发 `onUnbind` / `onDestroy`（可用于自动恢复钩子）；`settings put secure enabled_accessibility_services` 写入偶发静默失败，需同 shell 回读校验

## 四、路线图（未采纳，v0.4+ 候选）

- **指针 / 虚拟触控板**（OHO+ 虚拟触控板的无障碍近似）：直线箭头模式与摇杆光标模式 —— 参考 Fieldtrans/EdgeGesture、XGesture
- L 型手势（拖出后转向）—— Akış
- 环形菜单（边缘牵出玻璃环选单）—— Akış
- 单击 / 双击手柄 —— Vivid / EdgeGesture
- 全屏防误触（双滑确认）—— EdgeGesture
- 使用统计 / 15 种动画风格 —— EdgeGesture / Akış
- Shizuku 特权通道（freeform 弹出视图 / 真正分屏 / 强杀应用）—— EdgeGesture(Evilgodxu) / XGesture
