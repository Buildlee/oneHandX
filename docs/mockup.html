动效一览
· 页面进入：卡片淡入 + 上移 12dp，260ms 强调缓出
· 子页切换：右滑入 24dp + 淡入 280ms / 返回 200ms
· 按压：状态层着色 + 按钮 0.98 缩放（软弹簧）
· 开关：圆钮 220ms 弹簧 + 轨道渐变；滑块抓取圆钮 22→26dp
· 手柄指示：触摸 180ms 淡入、拖动跟手、长滑阈值 强调色高亮 + 轻震、松手 240ms 归位
· 全部动画走系统 VSync（120Hz 逐帧），跟随“移除动画”无障碍开关
· Apple 式精修（本轮反馈）：大标题 30px 负字距、勾选代单选、开关 50×30 近 iOS 比例、弹层阻尼弹簧

设计自查（impeccable × taste-skill）

Apple 式精修（Boss 反馈）✅ 大标题/负字距排版、勾选式选择、chevron 1.9px/38%、开关 50×30、滑块 27dp 白钮、弹层阻尼弹簧；ColorOS 采样令牌与结构保留
单一强调色（taste 硬规则）✅ 2 个蓝（#428AF7 深 / #377EF7 浅）为同一强调在两种主题下的实测取值，其余全部中性色
禁用项（渐变文字 / 玻璃拟态默认 / 侧边条纹 / 卡片模板阵列）✅ 无渐变、无毛玻璃默认、无徽章条纹；卡片按功能分组而非等宽阵列
对比度（正文 ≥4.5:1）✅ 深色 #ECECEC/#1A1A1A ≈ 12.6:1；次要 #959595 ≈ 6.3:1；浅色 #181818/#FEFEFE ≈ 17.1:1；次要 #737373 ≈ 4.7:1
提示文字也不低于 4.5:1✅ 副标题用 #959595/#737373 而非浅灰占位色
触摸目标 ≥48dp✅ 行高 58dp、开关实际热区 ≥48dp、滑块圆钮 22dp（按压缩放 26dp）
动效：意图明确、缓出、无弹跳滥用✅ 全部 ease-out/强调曲线，250ms 上下；无循环微动效、无入场错峰滥用（仅 ≤120ms 轻微错峰）
reduce-motion / 移除动画✅ 遵循系统“移除动画”设置（v0.5 实现项，已在动效规范中列明）
深色主题是一等公民（impeccable）✅ 令牌级双主题（非反色），采样自系统
ColorOS 特有语言（目标设备一致性）✅ 大圆角 24dp 卡片、白钮胶囊开关、#E0E0E0/#3A3A3C 关态、圆形返回钮、底部大圆角弹层、分组标题在卡片外
图标策略⚠️ 有意偏离：ColorOS 首页用彩色图标，但子页面（如“无障碍”）为纯文字列表；本应用采用“文字列表 + 强调色少量点缀”，减少杂色、贴近工具属性
动效强度 vs 设置类应用基线⚠️ 有意偏离：MOTION 由基线 2-3 上调至 4——手势工具的产品核心即“动的艺术”，且用户明确要求优雅动效；仍坚持无弹跳、无装饰性循环
