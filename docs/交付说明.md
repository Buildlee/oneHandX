## 一、这是什么

复刻三星「One Hand Operation+」的 Android 手势工具：屏幕左右边缘手柄，向内滑动（直滑 / 斜上 / 斜下 × 短滑 / 长滑 / 滑动保持）触发自定义操作。

**v0.4 为「真机对齐版」**：在三星 SM-S9180（S23 Ultra，Android 16 / One UI）上实操 OHO+ 全应用页面，抓取真实功能（50 个动作清单、手势设置、高级设置、触钮模型），据此补齐：
**虚拟触控板、浮动导航按钮、快捷操作（越过阈值立即执行）、手势角度、快速振动与振动强度、长距离滑动开关与按住持续时间、适配键盘（移到键盘上方）、主屏幕隐藏触钮、对齐触钮、指示动画（指示条/箭头/曲线 + 颜色）、搜索查找、颜色反转** 等。

应用不申请网络权限，全部数据仅保存在本机。

**v0.5 为「界面与手感」重制版**：设计令牌全部采样自 OPPO Find X10 Pro Max（ColorOS 17）真机截图，全界面重绘——大标题排版、24dp 大圆角分组卡片、自绘 50×30 胶囊开关与 27dp 白钮滑块、勾选式底部弹层、圆形返回钮；并补齐：优雅动效（入场错峰 / 按压反馈 / 浮层弹簧 / 手柄阈值光晕）、高刷适配（窗口声明 `preferredRefreshRate`，真机实测 144Hz 生效）、与 ColorOS 返回手势共存（手柄默认内移 26dp，真机实测 x=80 被系统抢占 / x=115 正常触发）、Android 15+ edge-to-edge 系统栏适配。

## 四、安装与使用

1. 安装 `OneHandPlus-v0.5.0-debug.apk`（覆盖安装保留设置；更新后需重新开启一次无障碍服务）；
2. 打开应用 → 「打开无障碍设置」→ 开启「OneHand+ 手势服务」；
3. 边缘手势：短滑 / 长滑（拖更远，可配置按住时长）/ 滑动保持（滑入后停住）/ 长按（原地按住）；
4. 手柄编辑页配置 10 个手势槽位（短滑、长滑、滑动保持各 3 方向 + 长按），并调整「距屏幕边缘」（默认 26dp，避开系统返回手势区）；
5. 「手势设置」区：快捷操作、手势角度、长滑开关与持续时间、快速振动、振动强度、适配键盘、主屏幕隐藏、对齐触钮；
6. 「虚拟触控板」「浮动导航按钮」绑定到任意手势后在屏幕上出现浮层；
7. 屏幕超时/旋转/亮度需「修改系统设置」；隐藏导航栏/颜色反转需一次 ADB 授权（应用内可复制命令）。

## 五、技术实现要点

- 手势判定：短滑 ≥ 触发距离；角度 ±角度阈值（可调）；长滑 = 距离 ≥ 长滑距离且（可选）按住 ≥ 持续时间；「滑动保持」= 滑入后停住 ≥ 保持时长；长按 = 原地按住 500ms；
- 快捷操作：越过阈值立即执行（短/长独立开关），松手不重复；
- 虚拟触控板：`TYPE_ACCESSIBILITY_OVERLAY` 触控板 + 光标窗口，`dispatchGesture` 注入点击（60ms 描迹）与长按（650ms），需 `canPerformGestures="true"`；
- 浮动导航按钮：三个按钮 → `performGlobalAction(BACK/HOME/RECENTS)`，抓手可拖动；
- 键盘适配：`getWindows()` 找 `TYPE_INPUT_METHOD` 且高度 ≥80dp 的可见键盘窗口，取其 top；「上方」模式把手柄窗口挤到键盘上方（长度按可用高度截断），「隐藏」模式 GONE；
- 主屏隐藏：`resolveActivity(MAIN+HOME)` 解析 Launcher 包名（`<queries>` 需声明 HOME 意图，否则 Android 11+ 包可见性会解析错误）；
- IME 状态比较只在该状态为「可见」时参与变化判断，避免隐藏态重复重挂载手柄（曾导致触摸被取消）；
- 颜色反转：写 `Settings.Secure.accessibility_display_inversion_enabled`（需 WRITE_SECURE_SETTINGS）；
- UI：全部界面用代码构建 + 自绘组件（SoftSwitch / SoftSlider / EdgeHandleView），令牌走 `values/colors.xml` 双主题；
- 动效：`Motion` 工具类统一缓动（PathInterpolator 强调曲线）、入场错峰、按压反馈、浮层动画、刷新率探测；
- 高刷：`Motion.maxRefreshRate()` 读取面板模式上限并写入手柄窗口 `LayoutParams.preferredRefreshRate`；
- 系统栏：`UiKit.applyInsets()`（Activity）与 `setDecorFitsSystemWindows(false)` + DecorView insets（弹层）；
- 其余：多手柄窗口、浮窗面板、导航栏策略、JSON 备份、包可见性、v1→v2 数据迁移等同 v0.3。

## 七、已知限制

1. **分屏**：Android 16 已移除 `GLOBAL_ACTION_TOGGLE_SPLIT_SCREEN` 处理（实测返回 false；`Unknown windowing mode`）；旧版系统可用，现代系统需 Shizuku/root。
2. **切换输入法**：Android 16 IMMS 忽略第三方 `showInputMethodPicker()`（日志实证）。
3. **隐藏系统导航栏 / 颜色反转**：依赖 `WRITE_SECURE_SETTINGS`（ADB 一次性授权）；policy_control 属历史机制，新版 Android 可能不生效；卸载前先「恢复显示」。
4. **Samsung 私有能力**（弹出视图/最小化弹窗/AI 多截图/录屏/扫一扫/单手模式/游戏助推器/模式/S Pen 手势等）无法由第三方应用实现（见 §3.2）。
5. **快捷面板内隐藏触钮**：未实现（OHO+ 的快捷面板属 SystemUI 快捷设置，第三方无稳定检测手段）。
6. 系统手势导航与边缘手势竞争：ColorOS 返回手势抢占最外侧约 24dp；v0.5 手柄默认内移 26dp 规避（可调），实测 x≥91px 正常触发。如仍冲突可增大「距屏幕边缘」或改用三键导航。
7. 手柄触控区会拦截其覆盖范围内触摸（官方文档亦如此）。
8. 模拟器无振动器/闪光灯：振动强度、手电筒未在设备实测（同源代码路径）。
9. 备份 JSON 仅本应用可识别。
