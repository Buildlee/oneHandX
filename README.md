# OneHand+（单手操作手势复刻）

复刻三星 One Hand Operation+ 核心功能的 Android 手势工具：
屏幕左右边缘手柄 + 每侧最多 3 个手柄 × 手势映射（短滑/长滑/滑动保持 × 3 方向 + 长按）+ 快速面板。

## 功能

- 左/右手柄，每侧最多 3 个，独立长度/位置/不透明度/手势映射
- 每手柄 10 个手势槽位：短滑/长滑/滑动保持（滑入后停住，时长可调）× 直滑/斜上/斜下 + 长按（原地按住）
- 31 种动作：返回、主屏、最近任务、上一应用、分屏*、通知面板、快捷设置、切换输入法*、截图、锁屏、电源菜单、
  手电筒、音量±、音量面板、静音、播放/暂停、上一曲/下一曲、屏幕超时、自动旋转、向左/向右旋转、切换导航栏*、
  打开应用、语音助手、快速工具、快速启动器、任务切换器、隐藏手柄…
- 浮窗面板：快速工具（亮度滑块 + 最多 6 个自定义按钮）、快速启动器、任务切换器
- 键盘弹出时暂停（输入法显示时自动隐藏手柄）
- 隐藏系统导航栏（实验，需一次 ADB 授权；停用服务/关闭开关自动恢复）
- 设置备份 / 恢复（JSON）
- 震动反馈、长滑震动提示、触发距离/长滑距离/保持时长可调、横屏开关、指定应用中停用
- 全部本地运行，不申请网络权限

（\* 分屏、切换输入法、切换导航栏受系统版本限制，详见任务目录《交付说明.md》「已知限制」；

参考项目调研见任务目录《参考项目研究.md》）

## 构建

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 使用

安装 → 打开应用点「打开无障碍设置」开启「OneHand+ 手势服务」→ 边缘滑动触发。
在应用内配置每个手柄的手势映射与快速面板；屏幕超时/旋转/亮度需「修改系统设置」权限。

## 已知限制

- 分屏 / 切换输入法：Android 12+（尤其 16）系统收紧了相应接口，实测 Android 16 无效（旧版系统可能可用）
- 隐藏导航栏：policy_control 为历史机制，新版 Android 可能无效；需 ADB 授权；卸载前先点「恢复显示」
- 系统手势导航会抢占水平边缘滑动（建议三键导航或斜向手势）
- 弹出视图（pop-up view）/ 虚拟触控板 / 边缘面板等 OEM 特权能力未实现
