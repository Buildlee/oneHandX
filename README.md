# OneHand+（单手操作手势复刻）

复刻三星 One Hand Operation+ 核心功能的 Android 手势工具：
屏幕左右边缘手柄 + 每侧最多 3 个手柄 × 12 个手势映射 + 快速面板。

## 功能

- 左/右手柄，每侧最多 3 个，独立长度/位置/不透明度/手势映射
- 每手柄 6 个手势：短滑/长滑 × 直滑/斜上/斜下（长滑未配置时回退短滑）
- 28 种动作：返回、主屏、最近任务、上一应用、通知面板、快捷设置、截图、锁屏、电源菜单、
  手电筒、音量 ±、静音开关、播放/暂停、上一曲/下一曲、屏幕超时、自动旋转、向左/向右旋转、
  打开应用、语音助手、快速工具、快速启动器、任务切换器、隐藏手柄…
- 浮窗面板：快速工具（亮度滑块 + 最多 6 个自定义按钮）、快速启动器（最多 6 个应用）、任务切换器（最近应用）
- 震动反馈、长滑震动提示、触发距离/长滑距离可调、横屏开关、指定应用中停用
- 全部本地运行，不申请网络权限

## 构建

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 使用

安装 → 打开应用点「打开无障碍设置」开启「OneHand+ 手势服务」→ 边缘滑动触发。
在应用内配置每个手柄的手势映射与快速面板内容；屏幕超时/旋转/亮度需「修改系统设置」权限。

## 已知限制

- 系统手势导航会抢占水平边缘滑动（建议三键导航或斜向手势）
- 分屏/弹出视图/虚拟触控板等需要系统特权的 OEM 能力未实现
